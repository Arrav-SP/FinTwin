# FinTwin

A performance test bench for PostgreSQL: synthetic banking workloads, recorded measurements, models that predict performance from the workload alone, and checks of those predictions against real runs.

This Space is a public demonstration. Anyone can read the recorded runs and use Predict and What if. Signing in with GitHub allows small runs (up to 16 workers, 100 TPS, 10 seconds; 10 a day).

- The data is synthetic. Nothing here is connected to a real financial system.
- The models were trained on a different machine, so measurements made here can differ from the predictions. The Validation page shows by how much.
- Runs made here are erased when the Space restarts.

Source and report: https://github.com/Arrav-SP/FinTwin
