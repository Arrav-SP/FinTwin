# Vercel Reference

`vercel-design-guidelines.pdf` is the primary reference for FinTwin's
interaction design and motion.

Use it to guide:
- page transitions
- hover states
- loading states
- button feedback
- sidebar transitions
- micro-interactions
- animation timing
- easing
- reduced-motion behavior

Do not copy Vercel branding, assets, text, or exact layouts.

FinTwin should use restrained, purposeful motion.
Animation must communicate state, hierarchy, continuity, or cause/effect.

Avoid:
- flashy animations
- decorative motion
- excessive bouncing
- glowing effects
- animated gradients
- attention-seeking transitions
